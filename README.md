# 🎬 Movie Explorer

A responsive movie and TV series search application built with **HTML, CSS, and JavaScript**.
The application uses the **OMDb API** to search for movies and series and display detailed information about them.

## ✨ Features

* 🔎 Search for movies and TV series
* 🎬 Display search results in responsive cards
* ℹ️ View detailed information about each movie or series
* ⭐ Display IMDb ratings
* 🎭 Display genre, actors, director, writer, runtime, country, awards, and plot
* ❤️ Add movies and series to a personal Watchlist
* 🗑️ Remove items from the Watchlist
* 💾 Persist the Watchlist using `localStorage`
* 📱 Responsive design for desktop and mobile devices
* ❌ User-friendly error messages when no results are found or an API request fails

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **OMDb API**
* **localStorage**

## 🔌 API

This project uses the **OMDb API** to retrieve movie and TV series information.

The API is used for:

* Searching for movies and series
* Retrieving detailed information
* Displaying posters, ratings, cast, plot, and other movie data

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Add your own OMDb API key to `script.js`.
4. Open `index.html` in a browser.
5. Search for a movie or TV series.

> **Note:** The API key is kept private and is not included in the public repository. You will need to use your own OMDb API key to run the project locally.

A live demo is **not currently available** because the application requires an OMDb API key, which is kept private and is not exposed in the public repository.
